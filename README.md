# Fraud Detection in Internet Banking using Machine Learning

This project applies machine learning to detect fraudulent transactions in internet banking. Using **KNN, Random Forest, and Logistic Regression**, the system achieves up to **90% accuracy** in identifying fraud.

---

## 📌 Project Overview
- **Goal**: Predict whether a banking transaction is fraudulent.  
- **Why**: Online fraud is a major financial risk; automated detection helps reduce losses.  
- **Dataset**: Sample transaction data (`fraud_dataset_example_2.csv`).  

---

## 🛠️ Tech Stack
- **Language**: Python  
- **Libraries**: pandas, NumPy, scikit-learn, matplotlib, seaborn  
- **Models**: KNN, Random Forest, Logistic Regression  

---

## 🔎 Approach
1. **Data Preparation**: Cleaning, encoding, scaling, train-test split.  
2. **EDA (Exploratory Data Analysis)**: Understanding distributions, correlations, anomalies.  
3. **Model Training**: Applied KNN, Random Forest, and Logistic Regression.  
4. **Evaluation**: Accuracy, Precision, Recall, F1-score, Confusion Matrix.  
5. **Result**: Best model achieved **~90% accuracy**.
